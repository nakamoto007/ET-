# challenges

コース固有の難所攻略ロジックを置くフォルダです。

`drive/`、`sensors/`、`control/` は汎用部品として残し、今後追加するマーク攻略、ゲート攻略、難所用シーケンスなどはここへまとめます。
既存のファイルは勝手に移動しません。

## 配置方針

- 小さい攻略は `challenges.cpp` / `challenges.h` に置く。
- 大きくなった難所は1つの難所につき1サブフォルダに分ける。
- 汎用的に再利用できる走行、センサー、ログ処理はここへ置かず、既存の役割フォルダへ置く。
- `app.cpp` からは難所ごとの公開関数だけを呼ぶ。
- 難所の調整値はできるだけ `config/ChallengeConfig.h` に置く。

## 現在の難所

| ファイル/フォルダ | 役割 |
| --- | --- |
| `challenges.cpp` | 既定経路は連続命令をまとめた型付きコマンド表で保持する。外部から受け取る `F/B/L/R` 文字列も、全体を事前検証してから同じ実行処理へ渡す。`F`と`B`は距離・速度を独立設定でき、直接隣接する`B→F`だけはB/F双方へ固定距離補償を行い、後退位置をholdして前進を緩加速する。現在の `L/R` は左右エンコーダの進み差を速度補正し、両輪が個別目標へ到達してからcoast、ブレーキの順で止める。各圧縮コマンドの開始・終了エンコーダ、方位、実行時間、結果は非同期の`command`ログへ記録する。 |
