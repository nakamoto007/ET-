# challenges

コース固有の難所攻略ロジックを置くフォルダです。

`drive/`、`sensors/`、`control/` は汎用部品として残し、今後追加するマーク攻略、ゲート攻略、難所用シーケンスなどはここへまとめます。
既存のファイルは勝手に移動しません。

## 配置方針

- 小さい攻略は `challenges.cpp` / `challenges.h` に置く。
- 大きくなった難所は1つの難所につき1サブフォルダに分ける。
- 汎用的に再利用できる走行、センサー、ログ処理はここへ置かず、既存の役割フォルダへ置く。
- `app.cpp` からは難所ごとの公開関数だけを呼ぶ。
- 難所の調整値はできるだけ `config/ChallengeConfig.h` に置く。
