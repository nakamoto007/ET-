## ライントレースをPD制御に変更

```mermaid
flowchart LR
    A[reflection取得] --> B[正規化]
    B --> C[目標値との差分]
    C --> D[フィルタ]
    D --> E[PD計算]
    E --> F[カーブ判定]
    F --> G[速度選択]
    G --> H[左右モータpower出力]
```

```text
error = target - normalized_reflection
derivative = (error - previous_error) / 0.003
turn = KP * error + KD * derivative
left_power  = base_power + turn
right_power = base_power - turn
```

## カラーセンサ読み取りを一元化

```mermaid
flowchart LR
    A[ColorSensorService] --> B[最新値キャッシュ]
    C[ライントレース] --> B
    D[BLEログ] --> B
    E[色検出] --> B
```

## 内容

- カラーセンサの直接読み取りを減らした
- ライントレース中は reflection を中心に使う
- ログや色検出は同じ最新値を見る形にした
- 読み取り競合を避けるためにセマフォで保護した
